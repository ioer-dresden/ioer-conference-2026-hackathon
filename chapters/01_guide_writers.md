# Guide for Writers
> Browser Editor

If you want to contribute concepts, text, or data stories to the **HaCLAthon** directly in your browser, this path is for you. We use a visual, browser-based editor (Decap CMS) to automatically convert your text into Pull Requests.

```{admonition} No GitHub account?
:class: tip
Simply write your text in Word, Google Docs, or Markdown, upload it to our [File Drop Folder](https://datashare.tu-dresden.de/s/XeBH775Pa8L5CiG), and email us. We will format and publish it for you!
```

## Step 1: Getting Access
1. Create a free [GitHub account](https://github.com/).
2. Email [fdz@ioer.de](mailto:fdz@ioer.de) with your GitHub username.
3. Accept the email invitation you receive from GitHub.

```{figure} ../resources/2026-05-06_invitation.webp
:name: Invitation
Invitation visible when viewing the [Github Repository of the HaCLAthon](https://github.com/ioer-dresden/ioer-conference-2026-haclathon/).
```

## Step 2: Logging In
1. Click the <strong><a href="/editor/">Collaborative Editor</a></strong> link.
2. Click **"Sign in with GitHub"** and authorize the IOER application.

```{figure} ../resources/2026-05-06_oauth_cms.webp
:name: Sveltia/Decap Login Screen
:figclass: fig-no-shadow
Sign-in through our Github integration.
```

## Step 3: Editorial Workflow

Your dashboard shows a Kanban board: **Drafts**, **In Review**, and **Ready**.
* Click **"New Book Chapter"** to start fresh.
* Click an existing chapter name to edit it.

```{figure} ../resources/workflow.webp
:name: Sveltia/Decap Workflow Screen
:figclass: fig-no-shadow
Stages of content contribution.
```

## Step 4: Writing and Formatting

Use the formatting toolbar (Bold, Italic, Lists) or type Markdown directly.

**Adding Images:**
Click the `+` icon in the toolbar and select "Image". The system automatically uploads your image to our `resources/` folder and inserts it into your text.

```{figure} ../resources/workflow2.webp
:name: Sveltia/Decap Edit Screen
:figclass: fig-no-shadow
Edit text in the editor.
```

## Step 5: Submitting for Review

When you are ready:
1. Click **Save**.
2. Change the status from **"Draft"** to **"In Review"**.
Our curation team will review, format, and publish your chapter to the live website at https://hack.conference.ioer.info.

```{figure} ../resources/2026-08-27_PR_sujit.webp
:name: Github Pull Request
:figclass: fig-no-shadow
Your contribution will be available as a Pull Request in Github and will be merged by the HaCLAthon team.
```

## Step 6: Iterate
Publish often! The HaCLAthon thrives on live collaboration. We welcome incremental contributions. Once we merge your changes, you can reopen the editor and continue right where you left off.

```{admonition} Style guidelines
:class: tip
For advanced formatting options, check out our [Formatting Conventions](content:references:formattingconventions).
```
